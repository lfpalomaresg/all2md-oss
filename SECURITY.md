# Seguridad

ALL2MD es un proyecto temprano. No se garantiza un plazo de respuesta ni mantenimiento de versiones antiguas.

## Comunicar una vulnerabilidad

Todavía está pendiente establecer un canal privado para informes de seguridad. No publiques detalles de explotación, documentos afectados ni información sensible en una incidencia pública. Puedes solicitar al mantenedor un canal privado con un mensaje genérico que no revele la vulnerabilidad; espera a que se acuerde ese canal antes de enviar los detalles.

Cuando exista un canal privado, prepara una descripción del impacto, los pasos de reproducción con datos sintéticos y la versión o el commit afectado. No envíes contraseñas, claves, cookies, tokens ni documentos reales.

## Manejo de documentos

- Utiliza archivos cuyo contenido y procedencia conozcas. El proyecto no ofrece un entorno aislado para analizar documentos hostiles.
- Revisa el Markdown antes de compartirlo: las hojas ocultas de Excel se incluyen y se etiquetan, y los documentos pueden contener información que no sea evidente a primera vista.
- Trata los archivos temporales y de salida como información del mismo nivel de sensibilidad que el documento original.
- Mantén actualizadas las dependencias cuando sea compatible con tu entorno y verifica de nuevo la conversión después de cambiarlas.

La conversión está concebida para ejecutarse localmente. La instalación de dependencias y la descarga inicial de algunos modelos requieren red; no se garantiza que todas las fases funcionen sin conexión.
